    आदेश सम्पादन (order editor)

    Inspirer—श्री अन्जनराज सापकोटा (जिल्ला न्यायाधीश)

    Developer: श्री शिवप्रसाद आचार्य (जिल्ला न्यायाधीश)

    मिति राख्नुहोस्, पेशी सूची ल्याउनुहोस् र आदेश तयार गर्नुहोस्

    पेशी सूचीबाट नेपाली अदालती आदेश वा फैसला तयार गर्नुहोस्। Preview का बहससहित र आदेशसहित button बाट बहस तथा छानिएको आदेश कागजातको व्यहोरामा समावेश गर्न सकिन्छ।

    ● Browser भित्रै प्रशोधन हुन्छ
    १

    Input source code

    मिति YYYYMMDD वा YYYY-MM-DD मा लेख्नुहोस्; नेपाली अंक पनि चल्छ। अदालतको वेबसाइटबाट सो मितिको सूची ल्याएर छानिएको न्यायाधीशको output स्वतः तयार हुन्छ।

    Source code मा भेटिएका न्यायाधीशहरू यहाँ स्वतः थपिन्छन्।
    Source code — फाइल Upload / Code Paste
    ⇧
    HTML वा TXT फाइल यहाँ राख्नुहोस्

    Drag & drop गर्नुहोस् वा तलको button बाट छान्नुहोस्

    फैसला तयार गर्न सहयोग गर्ने — शाखा अधिकृत, कम्प्युटर अपरेटर, इजलास नम्बर
    यी विवरण फैसला preview मा स्वतः आउँछन्। पुनः प्रयोग गर्न Save entries थिच्नुहोस्। फाँट सम्बन्धित मुद्दाको row बाट लिइन्छ। खाली छोड्न सकिन्छ।

    प्रत्येक table मा ALL+ default हो। ALL+ ले सबै content राख्छ, ALL ले हेर्न नभ्याइने/हेर्न नमिल्ने/स्थगित rows हटाउँछ, ALL- ले table नै हटाउँछ, र Custom मा serial हरू comma ले छुट्याएर लेख्नुहोस्—जस्तै: क, ग, २, ४।

    मिति राखेर पेशी सूची ल्याउनुहोस्, वा HTML/TXT upload अथवा code paste गर्नुहोस्।
